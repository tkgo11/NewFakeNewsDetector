# 판별 방식과 조사 자료

## 검색과 판정을 분리한 이유

이전 FakeNewsDetector는 네이버 검색 결과의 요약을 이어 붙여 입력 문장과의 코사인 유사도를 구한 뒤, 그 수치를 사실 등급으로 바꿨다. 검색 결과는 동일한 주제를 다루면서도 다른 사건을 설명하거나 원래 주장을 반박할 수 있다. 새 시스템에서는 검색이 후보를 찾고, 판정은 특정 주장에 대한 출처의 평가를 전달한다.

**AVeriTeC**은 실제 주장 4,568건에 온라인 근거와 판단 사유를 달았으며, 맥락 의존성과 시간상 뒤늦은 근거가 만드는 평가 문제를 논의한다. 이 프로젝트는 같은 맥락에서 판단을 확인할 수 있도록 원문과 날짜를 함께 표시한다. [AVeriTeC 논문](https://openreview.net/forum?id=fKzSz0oyaI)

**Factiverse 다국어 팩트체크 연구**는 주장 탐지, 근거 검색 및 재순위화, 판단을 별도 단계로 구성한다. 이번 구현은 사용자가 단일 주장을 직접 고르는 흐름과, 검토된 기존 자료를 찾는 방식으로 같은 구분을 적용했다. 한국어 검증 성능을 확인한 별도 모델을 포함하지 않는다. [Factiverse 사전 공개 논문](https://arxiv.org/abs/2606.08605)

**Google Fact Check Tools**는 출판사가 공개한 기존 ClaimReview를 검색한다. 검색에는 언어를 지정하며, 응답에서 원문 URL, 검증 기관, 검증일, 출처 평가를 보존한다. [Google API 문서](https://developers.google.com/fact-check/tools/api/reference/rest/v1alpha1/claims/search)

## 판정 규칙

1. 입력 언어를 지정하거나 한글 유무로 한국어와 영어를 고른다.
2. 로컬 자료에서 유니코드 NFC, 공백, 문장 끝 마침표를 정리한 뒤 동일 문장을 찾는다. 토큰과 문자 트라이그램의 Dice 계수로 가까운 후보를 정렬한다.
3. 온라인 검색을 선택한 경우 Google의 첫 페이지에서 일치하는 주장과 관련 자료를 가져온다. 원문에서 의미가 명확한 일부 한국어·영어 등급만 공통 판정으로 매핑한다. 그 밖의 평가는 원문 표현으로 표시한다.
4. 일치하는 자료의 평가가 같으면 해당 평가를, 평가가 다르면 출처 간 불일치를, 매핑할 평가가 없으면 검증 자료 발견을 표시한다. 일치 자료가 없으면 판정을 보류한다. 검색 유사도는 진위 판정에 사용하지 않는다.

로컬 자료의 요약과 평가는 연결된 공개 자료를 바탕으로 이 프로젝트가 작성했다. 기관이 자체적으로 부여한 등급이 있는 경우 `original_rating`에 기록한다. 자료와 링크가 수정될 수 있어 변경 시에는 원문을 다시 확인해야 한다.

## 검증 범위

회귀 테스트는 일치하는 주장, 날짜·수치·부정 표현의 변화, 평가가 엇갈리는 출처, API 키 미설정, 외부 검색 실패, 응답 검증, 웹과 API 동작을 점검한다. Google 호출은 테스트 응답을 이용해 확인한다. 기본 자료와 회귀 테스트는 실제 뉴스 전체에 대한 판정 정확도나 한국어 검색 재현율을 측정하는 벤치마크로 사용하기에 규모가 작다. 표현이 바뀐 주장이나 새로 등장한 주장에서는 자료가 있어도 판정이 보류될 수 있다.
